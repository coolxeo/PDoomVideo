# Determinism

- Same `(t, seed, size)` → same pixels.
- Seeded RNG only (`rng(seed)` pattern).
- No network fetches inside the paint path for cast art.
- External audio may exist (e.g. song bed) but LAN Soft Montessori openers often use
  `quiet: true` so karaoke does not fight the mood.
- Interactive later: log inputs; replay is part of the contract.
