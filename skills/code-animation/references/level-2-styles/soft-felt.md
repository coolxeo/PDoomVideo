# Style plate: soft-felt

## Intent

Soft Explorer felt diorama, expressed as **watercolor wash + ink**. Peaceful
Montessori toddler mood. Chestnut world house style.

## Mark order

1. Soft sky / meadow washes (few, large)
2. Character body mounds (wash)
3. Quills / ears / wings (looped or soft shapes)
4. Face features flat + ink
5. Tiny blush, highlights
6. Props (felt ball)
7. Optional title type in sky

## Edges

- Washes may undershoot their ink.
- No hard cel shadows.
- No photoreal fur.

## Palette

See `assets/palettes/soft-felt.json` and live `PAL` in `src/core.js`.

## Cast

Chestnut (cream + brown quills), white bunny (pink ear inners), yellow duckling
(orange beak/feet). Rosy cheeks OK. Always a little soft.

## Forbidden

- Lab / doom energy, guest horror cast on Soft Montessori shows
- Dense watercolor on every tiny feature (perf + muddy look)
- Swapping only colours while keeping Clawd block geometry

## Proof

Meadow play ~1.5s; yawn beat ~6.9s. Local `out/lan/` after bake.
