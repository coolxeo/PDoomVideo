# com.anthropic.claude-code

Client extension namespace for Claude Code. Portable skill content lives in
`../skills/code-animation`. Use `../scripts/link-claude-skill.sh` so Claude Code
loads the same files via symlink (no duplicate tree).

Marketplace install (when published):

```text
/plugin marketplace add coolxeo/PDoomVideo
```

Local prework on this box: run the link script after clone.
